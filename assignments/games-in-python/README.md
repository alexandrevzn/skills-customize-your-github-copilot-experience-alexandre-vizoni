
# 📘 Tarefa: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória em Python, implementando uma versão funcional do jogo da Forca.

## 📝 Tarefas
### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo da Forca em que o jogador tente adivinhar uma palavra oculta informando uma letra por vez antes que as tentativas se esgotem.

#### Requisitos
O programa completo deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Solicitar palpites de letras ao jogador.
- Exibir o progresso da palavra oculta, usando um formato como `_ _ _`.
- Controlar e exibir o número de tentativas incorretas restantes.
- Encerrar quando o jogador adivinhar a palavra ou ficar sem tentativas.
- Exibir uma mensagem informando se o jogador venceu ou perdeu.
